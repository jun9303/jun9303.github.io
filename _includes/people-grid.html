{%- comment -%} People grid with overlay profiles. Data: one file per person in _people/ (see _people/README.md); groups and their order in _data/people_groups.yml (pi, postdoc, graduate, undergraduate). The bio is the body of each person file. Each person is a box with a round photo, a name and a grey role line. Placeholders (placeholder: true) get "| Open position" at the end of the role line. The overlay has the photo on the left, the name, role and bio on the right, and the links in one line below both. Each person links to #person-, where slug is the person file name (sangjoon-lee.md gives person-sangjoon-lee). A repeated slug gets a numeric suffix (-2, -3, ...). A member without an id or a name gets the slug "member". Non-ASCII letters stay in the slug (person-josé-müller); people.js decodes the percent-encoded URL hash. The hidden .person-popup block with the same id contains the profile; assets/js/people.js opens it with Magnific Popup. Styles: assets/css/people.css. Photo URLs get "?v=", so a replaced photo file is not served from an old browser cache. {%- endcomment -%} {%- assign people_link_keys = "email,cv,website,orcid,scholar,linkedin,github" | split: "," -%} {%- assign people_used_slugs = "|" -%}
