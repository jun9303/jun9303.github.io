Include parameters post the post to show (the loop variable on /news/, page on a single page) body rendered HTML of the post; defaults to post.content single true on the single news page (title as h1, no link to itself) Output, top to bottom: grey line with the date and the tags ("Nov 1, 2026 | lab | recruiting"), title (links to the item page), body, photos with optional captions. Each item is one box with a 1px border (assets/css/news.css). Post front matter. One file per item: _posts/YYYY-MM-DD-short-name.md --- title: "Optional title" # optional; leave it out for a short post with no title date: 2026-11-01 # required; a time is optional: 2026-11-01 09:00:00 +0800 date_precision: day # optional; day (default) shows "Nov 1, 2026", # month shows "Nov 2026", year shows "2026" date_to_confirm: true # optional note to the editor that the date is not final; # the page does not show it (data attribute only) tags: [lab, recruiting] # optional; grey words after the date, shown as written (not links) images: # optional; 1 to 4 photos, a click opens the lightbox - /assets/images/news/2026-11-01-photo-1.jpg - path: /assets/images/news/2026-11-01-photo-2.jpg alt: "Short description of the photo" caption: "Photo by A. Links such as [NTU MAE](https://www.ntu.edu.sg/mae) are clickable. The full body shows in the feed. Notes - layout: news is set by the post defaults in _config.yml, so posts do not need to set it. - Item URLs are /news//, where is 10 hex characters made from the file name (_plugins/news_hash_permalink.rb). Renaming the file changes the URL. news_id or permalink in front matter replaces it. - When "title" is left out, Jekyll makes one from the file name (2026-11-01-lab-launch.md gets "Lab Launch"). This item hides that automatic title. It also hides a title you set if it is the same as the automatic one, so give the file a different name in that case. title: "" also means no title. Jekyll builds the automatic title from the file name, even if front matter sets slug:. With no title, the date links to the item page. - The automatic title still shows in the browser tab and in feed.xml. - Titles can use Markdown emphasis (*text*) and "|". In the feed the title is a link to the post, so a title that has its own [link](...) shows as plain text there. - Images can be plain paths or path + alt entries. Only the first 4 are shown. - caption is for credits, such as a figure from a paper: "Adapted from Lee & Marcus, J. Fluid Mech. 1014, A16 (2025), Fig. 10." It shows in small grey italic under the photo and after the alt text in the lightbox. Markdown links work in the caption. Do not repeat the citation in alt, because screen readers read both. - Jekyll skips posts with a date after the build date unless _config.yml sets future: true. {% endcomment %} {%- assign item = include.post -%} {%- assign body = include.body | default: item.content -%} {%- comment -%} Date text from date_precision {%- endcomment -%} {%- case item.date_precision -%} {%- when 'year' -%} {%- assign date_text = item.date | date: "%Y" -%} {%- assign date_iso = date_text -%} {%- when 'month' -%} {%- assign date_text = item.date | date: "%b %Y" -%} {%- assign date_iso = item.date | date: "%Y-%m" -%} {%- else -%} {%- assign date_text = item.date | date: "%b %-d, %Y" -%} {%- assign date_iso = item.date | date: "%Y-%m-%d" -%} {%- endcase -%} {%- comment -%} Rebuild the title Jekyll makes from the file name, to compare it with the front matter title.
