{%- comment -%} Sets person_slug for one person on the People page. The page id is person-. Used by people-grid.html (cards and overlays) and alumni-table.html (alumni rows), so both follow one rule. Call: {% include person-id.html slug=member.slug name=member.name %} The rule: 1. A written slug is used: "slug:" in a person file or in an alumni row, made lower case with dashes (slugify). 2. Without a slug, the name is used the same way: "Jane TAN" gives jane-tan. 3. If that id is already taken, -2, -3, ... is added. An id from a name does not take a written slug of a person file in a group of _data/people_groups.yml or of an alumni row, even one further down the page. If two people have the same written slug, the first keeps it and the next one is numbered. 4. Page order for 3: the groups as in _data/people_groups.yml, inside a group by "order" and then by file name, then the alumni rows from top to bottom. Numbers follow this order, so they can change when people are added or removed. Give each of two people with the same name a slug. Person files get slug: "" by default (_config.yml, defaults).
